# ThingsBoard UI (AntD Pro rewrite)

ThingsBoard frontend rewritten on Ant Design Pro v6 (`@umijs/max` + React 19 + antd 6).

Dev: `npm install && npm run dev` (proxy targets `localhost:8080`).
Gates: `npm run lint` (Biome + locale parity + tsc), `npm run build`, `npm run test`.

Docs live in the repository root: [`docs/`](../docs/) — see `docs/spec/v1-scope-and-acceptance.md` and `docs/adr/`.
