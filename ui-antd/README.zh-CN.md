# ThingsBoard 前端（AntD Pro 重写）

基于 Ant Design Pro v6（`@umijs/max` + React 19 + antd 6）重写的 ThingsBoard 前端。

本地开发：`npm install && npm run dev`（代理指向 `localhost:8080`）。
门禁：`npm run lint`（Biome + 双语 key 校验 + tsc）、`npm run build`、`npm run test`。

文档在仓库根目录 [`docs/`](../docs/)：见 `docs/spec/v1-scope-and-acceptance.md` 与 `docs/adr/`。
